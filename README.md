# Cryox Overlay Master

Fertiges OBS-Browserquellen-Projekt für SGT_CRYOX.

## Szenen

- `start/starting.html`
- `pause/brb.html`
- `ending/ending.html`

## OBS

Jede HTML-Datei als lokale Browserquelle öffnen:

- Breite: 1920
- Höhe: 1080
- FPS: 60
- Quelle herunterfahren, wenn nicht sichtbar: aktiviert
- Browser aktualisieren, wenn Szene aktiv wird: aktiviert

## BRB-Clipfenster

Die externe Clip-Browserquelle kommt in OBS unter `pause/brb.html`.

Position:

- X: 1136
- Y: 451
- Breite: 679
- Höhe: 334
